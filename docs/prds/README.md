# Product Requirement Documents

*PRDs are written when a new feature needs design before implementation.*

This folder contains draft, accepted, shipped, superseded, and exploratory PRDs.
The `Status` header in each PRD is the source of truth for that document; the
roadmap and supervisor log are the source of truth for implementation status.
